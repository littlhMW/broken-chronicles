# Mod idea

一个能够收集世界上遗落的碎片化叙事的日志/纸张。并且编录成册的MOD。允许模组/整合包创作者通过添加联动或者数据包，在游戏内产生多种文字记录类型：1.碎片page：以单页形式展示的一张文字碎片 2.书本book：一本书，允许存在多页，多张材质，允许是原版书。3.标签tag：在物品上的文字，允许给某一物品（苹果，剑）增加可读功能。能展开gui展示文本，不影响原本用途（可以吃掉可以打人）。这是两种类型，也就是可以替换里面的文字和材质，并且允许同时存在多种材质，例如我可以写日记背景的page，也可以同时存在是一张碎纸片的page，也可以是一张树叶，只要在对应的部分写好选择哪些就可以显示对应的材质。
它们主要区别就是依赖于什么物品，page就是只有一页的纸张的这种，book是原版的书那种，tag是依赖于物品。
核心功能是游戏允许制作一本收集册，以及游戏内的文字都是可以先右键阅读展开gui，接着选择收录，就可以把这个物品转换为收集录（破碎编年史）的一条条目：像是点击了收录就会解锁条目，即使物品摧毁了也能够保留在手记条目里面。
